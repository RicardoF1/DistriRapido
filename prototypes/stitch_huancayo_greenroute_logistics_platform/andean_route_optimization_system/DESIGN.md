## Brand & Style

The design system projects algorithmic precision, ecological responsibility, and high-altitude operational resilience. Designed for enterprise logistics directors, fleet dispatchers, and last-mile field couriers operating in Huancayo and the central Andean corridor, the aesthetic balances high-density industrial telemetry with crisp ecological clarity.

The visual style is **Corporate Modern with High-Density Precision**:
- **Clarity over ornament**: Strict geometric hierarchy engineered for high cognitive load environments (dispatch maps, elevation profiles, genetic algorithm iteration metrics).
- **Dual-context operational focus**: Desktop dispatch centers demand cool, low-strain informational density; mobile courier interfaces demand high-contrast tactile targets legible in intense Andean sunlight.
- **Eco-telemetry character**: Visual language that pairs computational routing sophistication with tangible emissions reduction metrics (kg CO₂ saved, regenerative braking zones, route gradient efficiency).

## Colors

The palette grounds high-tech routing intelligence in Andean ecology and logistics rigor.

### Key Roles
- **Primary (`#059669` - Deep Emerald)**: Core brand anchor, primary action elements, active routing paths, and confirmed eco-efficiency states. Deepens to `#065F46` (Forest) for pressed/selected states and high-contrast text accents.
- **Secondary (`#0F172A` - Deep Slate Navy)**: Structural frame, navigation sidebars, high-priority typography, and command bar containers. Paired with `#1E293B` for secondary card headers and telemetry panels.
- **Tertiary (`#10B981` - Vibrant Mint)**: Telemetry accents, algorithm convergence graphs, positive savings indicators, and system online health.
- **Alert / Accent (`#F59E0B` - Energetic Amber)**: Real-time route variances, vehicle maintenance alerts, steep elevation warnings, and intermediate fleet statuses.
- **Critical / Issue (`#EF4444` - Crimson)**: Road closures, vehicle breakdowns, missed delivery windows, and severe incidents.
- **Neutral Surfaces (`#FFFFFF` Pure White & `#F8FAFC` Clean Light Slate)**: Base canvases that isolate complex telemetry cards cleanly.
- **Borders & Dividers (`#E2E8F0` & `#CBD5E1`)**: Subtle structural definition engineered to prevent visual clutter in dense data grids.

### Status Palette (Spanish Logistics Terminology)
- **Planificado (Planned)**: Background `#F1F5F9`, Border `#CBD5E1`, Text `#475569`
- **En ruta (In Transit)**: Background `#ECFDF5`, Border `#A7F3D0`, Text `#065F46`, Indicator pulse `#10B981`
- **Entregado (Delivered)**: Background `#F0FDF4`, Border `#BBF7D0`, Text `#15803D`
- **Incidencia (Issue / Alert)**: Background `#FEF3C7`, Border `#FDE68A`, Text `#B45309`

## Typography

The type system pairs **Outfit** for structural headers, brand touchpoints, and numeric telemetry with **Inter** for ultra-legible administrative data and mission-critical driver workflows.

- **Outfit (Display & Metrics)**: Employs sharp geometric proportions that lend modernity to numerical outputs (e.g., elevation gradients, generation counts, CO₂ savings, fuel parity).
- **Inter (Operations & Body)**: Provides optimal tall x-height and neutral shaping for high tabular density, multi-line Andean addresses, and handheld driver confirmations.
- **Tabular Figures**: All metric values, timestamps, and fleet telemetry tokens must force tabular number spacing (`font-variant-numeric: tabular-nums`) to maintain alignment during real-time data streaming.

## Layout & Spacing

The system enforces a baseline 8pt grid with 4pt sub-increments for high-density components.

### Desktop Dispatch Dashboard
- **Shell Layout**: 3-pane responsive layout. Left collapsible operational navigation (64px collapsed, 240px expanded), center interactive map and routing workspace (fluid), right collapsible telemetry & genetic algorithm parameter panel (380px fixed).
- **Grid Density**: Data cards utilize compact paddings (`sm`: 12px) to maximize on-screen waypoints and multi-vehicle tracking without scrolling.

### Mobile Couriers (PWA Driver Mode)
- **Fluid Single Column**: Full-bleed edge gutters (`gutter-mobile`: 14px) with fixed top route telemetry and persistent bottom tactical action bar.
- **Touch Targets**: Strictly enforced minimum height of `3rem` (48px) for all driver-facing targets, with primary confirmation triggers expanding to `3.5rem` (56px) to allow one-handed glove-friendly interaction on uneven terrain.

## Elevation & Depth

Visual hierarchy uses low-contrast architectural borders augmented with calibrated cool-slate ambient shadows to maintain visual stability under heavy operational data loads.

- **Level 0 (Canvas Base)**: Pure `#F8FAFC`. Zero elevation.
- **Level 1 (Surface Cards & Panels)**: `#FFFFFF` bounded by a 1px crisp border in `#E2E8F0`. Shadow: `0 1px 3px 0 rgba(15, 23, 42, 0.04), 0 1px 2px -1px rgba(15, 23, 42, 0.04)`. Used for waypoint list items, algorithm metric modules, and dispatch list items.
- **Level 2 (Hover / Active Focus)**: Border `#CBD5E1`. Shadow: `0 4px 6px -1px rgba(15, 23, 42, 0.07), 0 2px 4px -2px rgba(15, 23, 42, 0.05)`. Used for selected route cards, active vehicle map popovers, and driver task cards.
- **Level 3 (Modals, Overlays, Bottom Sheets)**: Border `#E2E8F0`. Shadow: `0 20px 25px -5px rgba(15, 23, 42, 0.1), 0 8px 10px -6px rgba(15, 23, 42, 0.06)`. Used for PWA bottom action sheets, waypoint reordering panels, and emergency incidence dialogs.

## Shapes

The design system adopts a **Soft (Level 1)** geometric standard. This delivers a clean, professional enterprise aesthetic that maximizes usable visual canvas for high-density tabular and cartographic interfaces.

- **Base Controls (`rounded`)**: 4px (`0.25rem`) for compact telemetry tags, table badges, and density-critical data filters.
- **Cards & Containers (`rounded-lg`)**: 8px (`0.5rem`) for operational cards, metric widgets, map overlay controls, and route segment blocks.
- **PWA Bottom Drawers & Modals (`rounded-xl`)**: 12px (`0.75rem`) for tactile touch points and sliding panels on handheld courier devices.
- **Pills**: Reserved exclusively for dynamic status chips (e.g., *En ruta*, *Entregado*) and pulse live indicators.

## Components

### Buttons
- **Primary Dispatch**: Deep Emerald (`#059669`) background, `#FFFFFF` text, `rounded-lg` (8px), height 36px (desktop). Hover: `#065F46`.
- **Driver PWA Primary Action**: Full-width high-contrast container, height 56px, `#059669` background with `#FFFFFF` bold type, explicit haptic tap response, and loading state with integrated spinner.
- **Secondary / Ghost**: Outline `#E2E8F0`, background transparent, `#0F172A` text. Hover: `#F8FAFC` background.
- **Hazard Action (Reportar Incidencia)**: `#FEF3C7` background, `#B45309` border and text. Direct high-contrast alert triggering.

### Status Badges
- Strict pill architecture: padding `2px 8px`, `font-size: 0.75rem`, `font-weight: 600`.
- Includes a 6px circular indicator dot. If status is `En ruta`, the dot features an animated CSS ripple in `#10B981`.

### Telemetry & Genetic Algorithm Cards
- **Header**: Micro-label in `label-caps` (`#64748B`), uppercase tracking.
- **Value**: Bold Outfit numeral in `#0F172A` with inline secondary unit tag (`kg CO₂`, `ms`, `gen`, `%`).
- **Footer**: Micro-trend line or gradient elevation bar displaying real-time efficiency vs. baseline diesel routing.

### Waypoint & Delivery List Items
- **Desktop**: Compact row, 44px height, drag handle for manual override, waypoint sequence circle (`#0F172A` background with white index), address text in `Inter 14px`, dynamic ETA, and load utilization progress bar.
- **Driver PWA Card**: 88px minimum touch height, bold recipient name, one-tap native calling link, navigation launch intent button, and oversized sequence index (28px).

### Form Inputs & High-Contrast Touch Controls
- **Dispatch Inputs**: 36px height, `#FFFFFF` surface, `#E2E8F0` border, `#0F172A` text. Focus: 2px ring `#059669` with `#ECFDF5` background tint.
- **Driver PWA Inputs**: 48px minimum height, large checkboxes (24px x 24px) for POD (Proof of Delivery) checklist items with crisp green check marks (`#059669`).
